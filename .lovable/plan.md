# Animated Name Letter Accents

## Changes
- Animate a curated set of letters in both “Mona” and “Aswal” with staggered vertical jumps, while the remaining letters retain gentler movement.
- Give jumping letters alternating coral and violet accents with a small offset ink shadow, preserving the existing display font and readable name shape.
- Keep the animation lightweight in CSS rather than adding Three.js or GSAP; this avoids unnecessary download weight for a typographic effect.
- Disable the jumping and shadow movement when reduced motion is preferred.

## Verification
- Check the opening view at desktop and mobile sizes for clean spacing, readable text, smooth staggered motion, and no overlap.
